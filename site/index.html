Copy your files. Know they arrived.

Squeue is a free copy manager for Windows. It copies your files, checks every one, and picks up where it left off if a drive is unplugged.

How it works

Step 1

Drop your files

Drag a folder or files onto the window, or pick them with a button.

Step 2

Choose where they go

Squeue checks there is enough free space before it starts.

Step 3

Every file is checked

After copying, Squeue reads each file back and compares it with the original.

Built for copies you can't afford to lose

Checked copies

Each file gets a checksum on both sides, so a damaged copy is caught, not discovered months later.

Survives interruptions

If the PC crashes or a card is pulled out, Squeue continues from where it stopped. No half-written files are left behind.

Several drives at once

Jobs on different drives run side by side. Jobs on the same drive wait their turn, so nothing slows down.

Pause, resume, cancel

Stop a job whenever you need the drive for something else and carry on later.

History you can act on

See what was copied and when. If files failed, see which ones and why, and retry only those.

Private and free

No account, no ads and no internet connection. The source code is open on GitHub.

Installing

  1. Download SqueueSetup.exe and open it. It installs for your user only, so it doesn't ask for an administrator password.
  2. Windows may show "Windows protected your PC" because the installer isn't signed yet. Click More info, then Run anyway.
  3. Open Squeue from the Start menu. To remove it, use Installed apps in Windows Settings.
