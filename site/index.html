Built for copies you can't afford to lose

Checked copies

Each file gets a checksum on both sides, so a damaged copy is caught today, not discovered months later.

Survives interruptions

If the PC crashes or a card is pulled out, Squeue continues from where it stopped. No half-written files are left behind.

Several drives at once

Jobs on different drives run side by side. Jobs on the same drive wait their turn, so nothing slows down.

Space checked first

Squeue won't start a copy that can't fit, so you never end up with half a backup on a full drive.

History you can act on

See what was copied and when. If files failed, see which ones and why, and retry only those.

Private and free

No account, no ads, no internet connection needed. The source code is open on GitHub.

Installing takes a minute

  1. Download SqueueSetup.exe and open it. It installs for your user only, so it doesn't ask for an administrator password.
  2. Windows may say "Windows protected your PC" because the installer isn't signed yet. Click More info, then Run anyway.
  3. Open Squeue from the Start menu and drop your first folder on it. To remove it later, use Installed apps in Windows Settings.

Questions

Is it really free?

Yes. No trial, no ads, no account. The full source code is on GitHub.

What does "All checked" mean?

After copying, Squeue reads every file back from the destination and compares its checksum with the original. "All checked" means every copy matched. If one doesn't, Squeue copies it again, and if it still doesn't match it tells you and keeps the original.

What happens if I pull out the card mid-copy?

The job pauses and tells you which drive stopped responding. Plug it back in, press Resume, and it continues from where it stopped. Files that weren't finished are never left half-written under their real name.

Is it slower than Windows' own copy?

Copying alone is about as fast. Checking every file reads it a second time, so it takes longer; you can turn checking off in Settings for copies that matter less.

Why does Windows warn me about the installer?

The installer isn't code-signed yet, which costs money every year. Windows shows the warning for any unsigned program. The source code and the build script are public, so you can build it yourself if you prefer.

Does it work on Mac or Linux?

No, Squeue is Windows only (Windows 10 and 11, 64-bit).

Where are my history and settings stored?

In %LOCALAPPDATA%\Squeue on your PC. Nothing leaves your computer.
